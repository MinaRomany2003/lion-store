# 🦁 LION STORE

### Online Shopping & Store Management System

Lion Store is an e-commerce website designed to provide customers with an easy online shopping experience and give store administrators a simple dashboard to manage products, inventory, and customer orders.

## 🚀 Project Overview

The project consists of three main components:

- **Customer Website:** Allows customers to browse products, check prices and available sizes, and place orders.
- **Admin Dashboard:** Allows administrators to add, edit, and delete products, manage stock, and track customer orders.
- **Backend & Database:** Google Apps Script connects the website and admin dashboard to Google Sheets for data storage and management.

## ✨ Features

### Customer Website
- Browse available products.
- View product details and prices.
- Check available sizes and stock.
- Place orders online.

### Admin Dashboard
- Secure admin login.
- Add, edit, and delete products.
- Upload product images.
- Manage product sizes and quantities.
- View and track customer orders.
- Update order statuses.

## 🌐 Deployment

The customer website and admin dashboard are hosted using GitHub Pages.

Google Apps Script is used as the backend service, while Google Sheets stores the application data.

## 🔒 Security

The admin dashboard requires authentication through the backend service.

Sensitive credentials and private configuration data should never be stored in the public repository.
